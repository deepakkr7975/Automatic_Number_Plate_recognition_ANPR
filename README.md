# Automatic_Number_Plate_recognition_ANPR
Automatic Number Plate Recognition (ANPR) System
Developed an AI-based Automatic Number Plate Recognition system capable of detecting and extracting vehicle license plate information from images and video streams. Implemented computer vision and deep learning techniques using Inception-ResNet-v2 for feature extraction and OCR for character recognition. The system performs real-time vehicle monitoring, plate localization, text extraction, and data processing with improved accuracy and efficiency.

Outcomes:-
* Successfully detected and recognized vehicle number plates from images and video streams.
* Improved accuracy of license plate extraction using deep learning and OCR techniques.
* Automated vehicle identification and reduced manual monitoring effort.
* Achieved real-time processing for faster number plate recognition.
* Enhanced image preprocessing for better detection under different lighting and environmental conditions.
* Generated structured vehicle data for monitoring and record management.
* Strengthened practical knowledge of Computer Vision, Deep Learning, and OCR implementation.
